# Adapt Codex agent routing

Resolve this entry to its physical repository directory. Read the complete [shared workflow](../../../skills/adapt-agent-routing/SKILL.md). Use these bindings for a Codex evaluation.

- Trace the installed hooks through [event selection](../../hooks/delegation.py) to the [prompt fragments](../../prompts). Check the actual dispatch tool's model and effort choices, role overrides and the [persistent Astra loader](../../agents/astra-delegate.toml). Check account or host availability when evidence differs. A family selector in a loader is only evidence about the policy it loads.
- Look up the dated general index, cost to complete it, same-harness coding results by effort, and their individual tasks. Record the benchmark version, denominator, cost and elapsed time where published. If the agent page shows only its best setup, use the comparison table and select the Codex rows. [AA model comparisons](https://artificialanalysis.ai/providers/openai) · [AA Codex evaluations](https://artificialanalysis.ai/agents/coding-agents/codex) · [AA per-configuration results](https://artificialanalysis.ai/agents/coding-agents/comparisons/antigravity-cli-vs-codex)
- Cross-check provider pricing, context thresholds, cache read/write and output accounting for the applicable service tier. [OpenAI model guidance](https://developers.openai.com/api/docs/guides/latest-model) · [Pricing](https://developers.openai.com/api/docs/pricing) · [Codex subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)
- For an authorized local regression, use the [history replay](references/history.md). Audit examples of verifiable tracing, conflicting causes, isolated writing and consequential review. Compare only assignments whose original instructions gave the lead a routing choice under comparable constraints. Read the parent follow-up for disputed cases and check the proposed route against what was knowable at dispatch time.
- From the dev-kit root run `python3 -B -m unittest discover -s codex/hooks`. Compare installed `SessionStart` and `SubagentStart` output for current, preceding and unknown model families with the source fragments. Exercise the persistent role command. Check permission to delegate, ownership of writes, role isolation and the lead's final judgment.
- Use `codex debug prompt-input` to check skill discovery. To verify that a hook reached the model input in full, compare an actual CLI request with the expected text. A loopback test provider can capture a synthetic request before inference. In a temporary home retain the trusted handler's matcher, group and handler indexes. Check its explicit or documented default limit. Attribute routing decisions and answer quality to actual executions. [Codex hook output](https://learn.chatgpt.com/docs/hooks#large-hook-output)
