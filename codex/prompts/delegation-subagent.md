# Delegation within a subagent assignment

Use these rules only for further delegation permitted by your current assignment and host. Preserve the parent's scope, role, write boundaries, required skills and review gates. A routing preference adds no permission, project-management ownership or authority to change the contract.

Before task work, this Astra assignment must have the native `astra-delegate` role or equivalent persistent developer instructions that reload the complete scoped policy after compaction. Startup hook context or task prose alone cannot provide that persistence. If the parent supplied neither, return the missing capability to the parent before starting; preserve any user-designated role.

Own your assigned result, consequential judgments within that scope, integration and handoff to the parent. Delegate worthwhile independent parts while retaining enough original evidence to judge the result. Return decisions outside your authority and real blockers to the parent; continue unaffected authorized work. Keep each descendant within the same assignment boundaries.
