# Delegation and task context

Delegate substantive work when added coverage or parallel benefit outweighs startup, reading, verification and integration cost. Reuse sufficient current evidence or continue with a suitable existing executor first. Keep one owner for related investigation; do not split it by tool call or file, or create tasks to fill capacity. Dispatch worthwhile independent workstreams early. Handle trivial work, tightly coupled consequential reasoning and targeted primary-source checks directly. A missing fact, permission or tool is not solved by changing models.

Give the executor the result, scope/target version, authorization, constraints, acceptance criteria, evidence index and remaining gap. Before dispatch, read the smallest original working set likely to be used repeatedly by parent and descendants: relevant instructions, contract, stable diff and central code. Reuse current reads; leave specialist-only exploration delegated.

Prefer `fork_turns: "all"` for substantial shared context with the same model/effort and relevant history, when the host preserves the shared prefix, required roles, permissions and independence. Read shared originals before forking; append the child assignment without copying them again. An independent review lead may fork its primary-material context before forming findings. Use `fork_turns: "none"` for model/effort changes, unrelated history, fixed project-stage dispatch, or when reviewer history would include the target's authorship/implementation or prior review judgments; pass sufficient original inputs and an evidence index. Never fork an author's history to establish independent review. Inherited main/controller routing does not transfer those responsibilities. Do not change model routing or preload unrelated material for cache hits; parent reads alone do not transfer to clean children. Claim cache savings only from actual usage evidence. Cache reuse requires a matching rendered prefix and compatible request settings. Compare exposed cached and uncached input, cache writes where available, latency and total work; identical file contents alone do not prove reuse.

Load only applicable role/mode inputs. Inputs already present in the current context need no reread while unchanged; preserve mandatory instruction reloads, complete contracts and necessary primary-source judgment. Summaries index original inputs. Executors check and repair their work before handoff.

When explicitly selecting an Astra subagent, use the native `astra-delegate` role and pass the selected model and effort explicitly. Its persistent developer instructions reload the scoped policy after compaction; startup hook context alone is insufficient. If the host cannot select that role or provide equivalent persistent developer instructions, report that missing capability for the Astra assignment. Preserve any user-designated role and required independent review.
