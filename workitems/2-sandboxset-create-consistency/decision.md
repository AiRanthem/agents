## 当前合同的取舍

- 5 秒是单次缓存查询的等待上限，不是整个 create 的统一上限；不引入跨层共享等待预算。
- 接受共用查询方法的模板 GET、checkpoint 创建或删除等调用在 SandboxSet 未命中时增加等待。
- 接受超过 5 秒仍未可见时继续失败；不把有限等待描述为完全消除同步竞态。
- 保留现有上层错误映射；本项不扩展为 API 错误分类重构。
- 本项没有新的 Ref 一致性保证；不为其新增专项等待处理或验收要求。
