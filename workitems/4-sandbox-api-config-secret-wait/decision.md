## 2026-11-17 设计 v1 批准

2026-11-17，Codex 主会话提出完整合同及设计路径，用户回复“确认”。本次批准涵盖：

- 启动参数 `--ready-before-config`，默认 `false`，仅在设置了 `--secret-config` 时生效；关闭时保留当前启动行为，无 Secret 引用时不改变静态来源。
- 开启后健康与现有观测接口可用，控制 API 和 Envoy 业务入口在初始配置及后续运行时初始化完成前返回 `503`。
- Secret 缺失、无效或首次应用失败时持续等待；配置补齐后同进程恢复业务。依赖有效配置的后台任务延后，其他致命启动错误保持原有失败语义。
- 不由进程推算配置等待总期限；新模式下 startup probe 成功后不再限制配置等待时长。
- 开关仅控制首次启动，正常运行后的热更新保留既有语义。
- 正式设计保存于 `workitems/4-sandbox-api-config-secret-wait/spec.md`，版本 1。

批准来源为紧接完整合同确认问题的用户消息“确认”，不是根据沉默、项目状态或测试结果推断。
