# 支持通过飞书消息自动唤醒 OpenClaw

## 目标

当承载 OpenClaw 的 Sandbox 处于休眠（Pause）状态时，用户从飞书发送 IM 消息后，自动唤醒该 OpenClaw。

## 范围

### 已明确的业务场景

1. OpenClaw 运行在 Sandbox 中，并通过 IM 频道接入飞书。
2. 承载 OpenClaw 的 Sandbox 可能因各种原因进入休眠（Pause）状态。
3. Sandbox 休眠后，用户从飞书发送 IM 消息，需要自动唤醒该 OpenClaw。

本次补充面向 Sandbox 已存在且处于 Pause 状态的场景；具体休眠原因尚未限定。

### 待明确的细节

- 飞书消息的触发范围与条件，以及消息与目标 Sandbox / OpenClaw 的对应关系。
- 唤醒完成的判定、耗时要求和失败时的行为。
- 触发唤醒的消息在唤醒后的处理要求。
- 权限边界、目标代码仓库及实现载体。

## 验收条件

基础验收场景：OpenClaw 已在 Sandbox 中运行并通过 IM 频道接入飞书；当该 Sandbox 处于 Pause 状态时，用户从飞书发送 IM 消息，能够触发对该 OpenClaw 的自动唤醒。

具体成功判定、消息处理、时延及异常场景的验收标准待明确。
