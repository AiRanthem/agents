# Develop Work Item

Advance the authorized phase from the management project, using the actual source workdir for code. Read [discussion and authorization](../advance-project/references/discussion-and-authorization.md). Requirement creation alone does not authorize design or implementation.

- For ordinary single-item work, use [ordinary development](references/ordinary-development.md) and maintain project documents directly.
- For requested autonomous advancement, use [advance-project](../advance-project/SKILL.md); the controller owns the stages and formal records.
- A dispatched executor uses [stage-executor](../advance-project/references/stage-executor.md) and its assigned skill, returning evidence within its write scope.

Read-only planning remains read-only. Tests and AI review do not establish human acceptance or delivery. Preserve unrelated work, actual source locations and useful prior evidence. Commit and push completed project-record edits; source publication requires covering user instructions.
