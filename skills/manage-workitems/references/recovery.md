# Resume project work

Read the project's original instructions, current records, Git status and affected source locations. Continue from actual local files and useful existing work. Git provides previous committed versions; credentials, unpublished source and separate environments remain at their recorded locations.

For interrupted writing, inspect affected files and complete or correct them within existing task authorization. Commit completed project changes and push the configured branch. A failed push leaves a local commit; resolve the actual Git issue and retry normally. Preserve unrelated edits.

When records disagree with actual work, investigate the original contract and evidence, then correct the records directly. Preserve genuine attribution and user decisions; report unknown facts. New consequential scope or permission questions go to the user, while covering authorization remains valid.

Before repeating an uncertain external action, inspect the service for its actual outcome. Preserve known IDs and useful response evidence. Identify a possibly created item before creating another.

Read original main-workspace/source instructions before dependent work. Missing code or ambiguous locations require the actual location or user decision; project records alone do not restore an environment. Requested local removal follows [delete-project](../../delete-project/SKILL.md), preserving unrelated workspaces and external history.
