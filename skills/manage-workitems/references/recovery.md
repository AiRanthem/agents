# Restore and recover a project

Cloning the exact configured project branch restores published current requirements, design, current pointer-bound evidence and project state. Git history provides prior versions. It does not restore machine-local bindings, tools, credentials, unpublished code or the separate main workspace. Start the agent at the project root and read its generated `AGENTS.md`. Install missing shared skills through their installation contract.

Use `project.py status` for the fixed reported facts. For an interrupted operation, run only its returned resume command and then follow the [status table](commands.md#fixed-write-workflow). Preserve local identity and recovery files. Report unresolved ownership, publication or backend facts without choosing another journal action, manually editing YAML, repeating an uncertain create or assuming a timeout releases ownership.

The program reports confirmed failures before any push separately from unresolved publication outcomes. These rejected attempts do not block `status`; their local intent remains available. A retained candidate with an uncertain push remains subject to publication recovery checks.

Schema-1 projects permit diagnostic reads and explicit `migrate`. `upgrade-project` runs that deterministic migration/instruction refresh; active ownership and unresolved sync block it with concrete facts. Source hashes make repeat execution a no-op. The agent writes complete current business instructions from the explicit current source when the program reports that input is needed. Existing user-maintained authority remains valid; migration does not routinely request reapproval. If the source leaves a real business change or permission unknown, report that specific gap. Migration does not retain obsolete prompts as active project content; earlier versions remain in Git history.

The program returns required original main-workspace instruction paths. Read them before dependent work. If a binding, original instruction or code location is missing, report the listed missing input; do not infer a new path or repair layout yourself. Changing a binding does not move dirty worktrees or transfer a claim. Follow [the command contract](commands.md): `status: blocked` with `code: stale_ticket` returns the sole allowed restart command, while `code: stale_evidence` is blocked without a continuation command until current authorization/review evidence is supplied.

Project removal uses [delete-project](../../delete-project/SKILL.md) with an exact authorized local manifest. It preserves remote branches and Aone history by default, along with main-workspace roots, shared environments, sibling projects and unrelated worktrees. Unpublished content and uncertain external outcomes require preservation or resolution before removal; removal is not a recovery shortcut.
