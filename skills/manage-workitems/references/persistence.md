# Program-owned persistence

Scripts handle ordinary persistence under the command workflow below. For script blockers or defects, use the separate [user-authorized manual recovery](recovery.md#user-authorized-manual-recovery) contract, including reconciliation of uncertain transactions against actual external state.

A completed checkpoint means the configured project Git ref and every enabled backend have verified the requested state. The program performs guarded publication, input-byte checks, graph checks, durable external intent, readback and receipts. In ordinary operations, agents use `begin`/returned `finish_command` or the typed autonomy coordinator interface, which invokes the same guarded workflow; they do not assemble bundles, metadata JSON mutations, Git commits or Aone requests for project records. The advancing agent supplies actual report artifacts and content attribution; native task management stays outside project state.

`published` ends a successful operation; `no_op` ends an unchanged operation without a commit or backend call. `partial` retains the same intent and returns the only resume command. For `blocked` with `code: stale_ticket`, execute only its returned `next_command` to begin again with current inputs. `blocked` with `code: stale_evidence` returns no `next_command` or `finish_command`; obtain current authorization/review evidence and report the blocker. Other blockers or missing input report the precise facts needed and stop that operation; an autonomous coordinator may continue unrelated ready items within its authorization. In ordinary recovery, follow these returned branches and let the program inspect remote refs, compute receipts and select journal recovery. Reconcile uncertain creates before retrying and report synchronization only after verified completion.

Operate on one local project in sequence, completing or recovering the current operation before the next. Any local session may continue from current artifacts and operation records under the existing authorization. Input-byte checks keep evidence applicable after changes; short-lived local transaction locks protect publication and recovery writes. An uncertain external outcome retains its recovery identity until reconciled against actual remote facts.

Autonomy state retains scoped authorization, operation provenance, actually approved contract texts, current content-bound work products and human acceptance. Author/reviewer attribution records substantive contribution and independence. The advancing agent manages native task lifecycle and serial project progression. Human acceptance binds current artifacts and reviewed code; it substitutes for neither source submission nor delivery.
