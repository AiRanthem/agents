# Program-owned persistence

A completed checkpoint means the configured project Git ref and every enabled backend have verified the requested state. The program performs guarded publication, exclusive ownership, graph checks, durable external intent, readback and receipts. Agents use `begin`/returned `finish_command` or the typed autonomy coordinator interface, which invokes the same guarded workflow; they do not assemble bundles, metadata JSON mutations, Git commits or Aone requests for project records. The advancing agent supplies actual report artifacts and content attribution; native task management stays outside project state.

`published` ends a successful operation; `no_op` ends an unchanged operation without a commit or backend call. `partial` retains the same intent and returns the only resume command. For `blocked` with `code: stale_ticket`, execute only its returned `next_command` to begin again with current inputs. `blocked` with `code: stale_evidence` returns no `next_command` or `finish_command`; obtain current authorization/review evidence and report the blocker. Other blockers or missing input report the precise facts needed and stop that operation; an autonomous coordinator may continue unrelated ready items within its authorization. Use these branches exactly; do not inspect remote refs, recompute receipts, choose a journal recovery path, blindly repeat uncertain creates or report a partial result as synchronized.

Ownership is published before implementation can begin. An uncertain external outcome retains its recovery identity and any required ownership. A new machine/session does not infer takeover from time, a missing local cache or an unchanged HEAD. Explicit handoff remains necessary within the program's gates.

Autonomy state retains scoped authorization, claim/audit provenance, actually approved contract texts, current content-bound work products and human acceptance. Authors/reviewers identify substantive contribution and independence, not running executors. Native task IDs, liveness and host receipts belong to the advancing agent. Human acceptance binds current artifacts and reviewed code; it substitutes for neither source submission nor delivery.
