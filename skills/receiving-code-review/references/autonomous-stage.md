# Autonomous fix stage

Take one controller-assigned work item and fix attempt, with the current code artifact, review report, contract, permitted worktree/report paths and result identity. Verify they match before editing. Return stale, conflicting or missing inputs to the controller without taking over another attempt.

Evaluate feedback and fix supported findings within the approved contract without another target-confirmation round. Implementer self-review and meaningful affected verification remain required. The controller owns later independent re-review, user discussion and formal registration.

Write only designated source or candidate/report artifacts; keep source uncommitted. Do not call project CLI, update formal project documents or metadata, register review results, or publish project Git/Aone changes. Return proposed contract corrections as candidate material for the controller.

Supply actual dispositions, changes, check results and a reproducible dirty artifact identity under the assigned attempt. Close descendants and their resources before returning. You may organize descendants and choose their models/effort under actual host capabilities; ordinary main-agent routing and automatic escalation rules do not apply. Host safety and permission boundaries remain in force.
