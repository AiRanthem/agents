# 恢复项目工作区

从 `git@github.com:AiRanthem/agents.git` 恢复专用分支 `projects/oka-daily-open-source`，在管理根目录阅读 [AGENTS.md](../AGENTS.md)、[项目配置](project.yaml)、[业务指令](business-instructions.md)和相关工作项。共享技能缺失时，从同一仓库的 `devkits/master` 分支取得 airan-dev-kit，并按其安装说明恢复。

以当前文件、Git 状态和远端分支核对已保存及已发布的记录。直接修正已授权范围内的记录，提交相关文件并普通推送配置分支。推送失败时保留本地成果。外部操作结果不明时，先核验远端实际结果，再决定是否重试。保留已知外部 ID 和响应证据。

主工作区位置见[本机绑定](main-workspace.json)，业务操作先阅读原始工作区和源码仓库指令。Git 保存以往的项目记录。单独维护的环境、凭据和未发布源码须从实际位置恢复。保全本地源码、报告、私密恢复数据和实际资产路径，依据已核验的记录定位缺失资产。按需使用 `upgrade-project` 更新项目结构和指令。
